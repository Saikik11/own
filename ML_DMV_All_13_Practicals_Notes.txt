1.  AIM To implement Principal Component Analysis (PCA) on the Wine

2.  THEORY Principal Component Analysis (PCA) is an unsupervised machine
    learning algorithm used for dimensionality reduction. It transforms
    a dataset containing correlated features into a smaller set of new,
    uncorrelated features called principal components.

PCA uses an orthogonal transformation to convert the original variables
into a new coordinate system. The first principal component captures the
maximum variance in the dataset, while subsequent components capture the
remaining maximum possible variance.

PCA is based on mathematical concepts such as variance, covariance,
eigenvalues and eigenvectors. It helps remove redundant information,
reduce computational complexity and improve data visualization.

In this practical, PCA is applied to the Wine dataset containing
features such as alcohol, ash, magnesium and other chemical
measurements. The original features are transformed into fewer principal
components while preserving important information.

    features in a dataset while retaining the most important
    information.
-   Variance: Measures how much the values of a feature differ from
    their mean.
-   Covariance: Measures how two variables change together. Positive
    covariance indicates that variables tend to increase together, while
    negative covariance indicates opposite movement.
-   Correlation: Represents the strength and direction of the
    relationship between two variables. Its value ranges from -1 to +1.
    +1 indicates perfect positive correlation, -1 indicates perfect

-   Eigenvectors: Determine the directions of the new principal
    component axes.
-   Standardization: Transforms features to a comparable scale, commonly
    by subtracting their mean and dividing by their standard deviation.
-   Principal Components: Newly generated, linearly uncorrelated
    features that represent important variation in the original dataset.

1.  AIM To implement Linear Regression using Python and apply regression
    techniques to establish relationships between independent and
    dependent variables for predicting numerical values.

2.  THEORY Regression is a supervised machine learning technique used to
    identify relationships between variables and predict continuous
    numerical values.

Linear Regression is one of the simplest and most widely used regression
algorithms. It establishes a linear relationship between independent
variables and a dependent variable.

The dependent variable is the output that needs to be predicted, while
independent variables are the input features used for prediction.

In Simple Linear Regression, one independent variable is used to predict
the dependent variable. In Multiple Linear Regression, two or more
independent variables are used.

The regression model calculates the best-fit line by minimizing the
difference between actual and predicted values. This process commonly
uses the Sum of Squared Residuals (SSR).

Simple Linear Regression: y = b0 + b1x

Multiple Linear Regression: y = beta0 + beta1x1 + beta2x2 + … +
betarxr + error

Where y is the dependent variable, x is an independent variable, b0 is
the intercept, b1 is the slope and error represents random error.

Linear Regression is useful for predicting numerical values and
understanding how changes in input variables affect the output.

2.  THEORY Support Vector Machine (SVM) is a supervised machine learning
    algorithm used for classification and regression problems.

In classification, SVM separates data points belonging to different
classes by finding an optimal decision boundary called a hyperplane.

The main objective of SVM is to identify a hyperplane that maximizes the
margin between different classes. The margin is the distance between the
hyperplane and the closest data points belonging to different classes.

The data points closest to the hyperplane are called support vectors.
These points play an important role in determining the position and
orientation of the optimal hyperplane.

For image classification, an image is represented as an array of pixel
values. These pixel values are converted into feature vectors and
supplied to the SVM classifier.

SVM is particularly useful for high-dimensional datasets and can
classify complex patterns using suitable kernels.

PRACTICAL 4: K-MEANS CLUSTERING AND ELBOW METHOD Dataset: Iris dataset
Title: Clustering Analysis.

1.  AIM To find the optimum number of clusters using the Elbow Method
    and apply the K-Means Clustering algorithm to the Iris dataset.

2.  THEORY Clustering is an unsupervised machine learning technique used
    to group similar data points into different clusters without
    predefined class labels.

K-Means is a centroid-based clustering algorithm that divides an
unlabeled dataset into K different clusters. Each cluster is represented
by a centroid, which is the center point of that cluster.

The algorithm assigns every data point to its nearest centroid based on
distance. After assigning the points, the centroids are recalculated
using the mean of the data points belonging to each cluster.

This process is repeated until the centroids stop changing or the data
points remain in the same clusters.

The Elbow Method is used to determine the optimum number of clusters. It
calculates the Within Cluster Sum of Squares (WCSS) for different values
of K and plots the results.

The point at which the WCSS reduction starts becoming less significant
is called the elbow point. This point helps identify the appropriate
number of clusters.

In this practical, the Elbow Method is used to determine the optimum
number of clusters before applying K-Means to the Iris dataset.

21. SEPARATE THEORETICAL CONCEPTS USED

-   Clustering: An unsupervised learning technique used to group similar
    data points.
-   Unsupervised Learning: A machine learning technique in which the
    model learns patterns without predefined output labels.
-   K-Means Algorithm: An iterative clustering algorithm that divides a
    dataset into K clusters based on distance from cluster centroids.
-   Cluster: A group of data points that share similar characteristics.
-   Centroid: The central point of a cluster, calculated as the
    arithmetic mean of the coordinates of its data points.
-   Euclidean Distance: Straight-line distance between two data points.

-   WCSS: Measures the total squared distance between each data point

-   Elbow Method: Determines the optimum number of clusters by plotting
    WCSS against different values of K.
-   Convergence: Occurs when centroids stop changing significantly or
    cluster assignments remain the same.

PRACTICAL 6: REINFORCEMENT LEARNING USING Q-LEARNING Environment: Maze
exploration Title: Reinforcement Learning: Maze Exploration.

1.  AIM To implement Reinforcement Learning using the Q-Learning
    algorithm in a maze environment, where an agent learns to reach the
    goal while avoiding obstacles.

2.  THEORY Reinforcement Learning is a type of machine learning in which
    an agent learns to make decisions by interacting with an
    environment.

The agent performs actions in the environment and receives rewards or
penalties based on its actions. The main objective is to learn an
optimal policy that maximizes the total expected reward.

Q-Learning is a model-free reinforcement learning algorithm used to
learn the best action to perform in a particular state.

It maintains a Q-table containing the values of different state-action
pairs. These Q-values represent the expected future rewards for taking
particular actions in particular states.

The agent selects actions using an epsilon-greedy policy. This policy
balances exploration, where random actions are selected, and
exploitation, where actions with higher Q-values are selected.

Q-Learning update equation: Q(s,a) = Q(s,a) + alpha [r + gamma max
Q(s’,a’) - Q(s,a)]

Where: Q(s,a) = Current Q-value alpha = Learning rate r = Reward
received gamma = Discount factor s’ = Next state a’ = Possible next
action

In this practical, the maze is represented as a grid containing empty
spaces, walls, a starting position and a goal position. The agent learns
to navigate the maze by repeatedly exploring it and updating its
Q-table.

23. SEPARATE THEORETICAL CONCEPTS USED

-   Reinforcement Learning: A machine learning technique in which an
    agent learns by interacting with an environment and receiving
    rewards or penalties.
-   Agent: The learner or decision-maker that performs actions in the
    environment.
-   Environment: The surrounding system in which the agent operates.
    Here, it is the maze grid.
-   State: The current position or situation of the agent.
-   Action: A movement or decision made by the agent. In the maze,
    actions are Up, Down, Left and Right.
-   Reward: Positive or negative feedback received after performing an
    action.
-   Q-Table: Stores the expected value of performing each possible
    action from each state.
-   Q-Learning: A model-free reinforcement learning algorithm that
    updates Q-values based on rewards and estimated future rewards.
-   Exploration: Trying different actions to discover new possibilities.
-   Exploitation: Selecting the action that currently has the highest
    estimated Q-value.
-   Epsilon-Greedy Policy: With probability epsilon, selects a random
    action; otherwise, selects the action with the highest Q-value.
-   Learning Rate: Controls how much newly received information changes
    the existing Q-value.
-   Discount Factor: Determines the importance of future rewards
    compared with immediate rewards.
-   Episode: One complete training attempt, usually from the initial
    state until the goal or a stopping condition is reached.

-   Decision Tree: Supervised learning algorithm that uses conditions
    and decision rules to classify data.
-   Random Forest: Combines multiple decision trees to produce a final
    prediction through majority voting.
-   Accuracy: Percentage of correct predictions made by a model.
-   Precision: TP / (TP + FP). Measures how many customers predicted as
    churners actually belong to the churn class.
-   Recall: TP / (TP + FN). Measures how many actual churners are
    correctly identified.
-   F1-Score: Harmonic mean of precision and recall. F1 = 2 x (Precision
    x Recall) / (Precision + Recall).
